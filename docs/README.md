# ChatHub 文档总览

> ChatHub 是当前主项目。Git 跟踪的项目交付资料包括需求、架构、协议、测试、验收、交接和部署文档。

## 文档分类

- `W8-*.md`、`W9*.md`：已确认的需求与验收边界；
- `架构规划.md`、`代码架构重规划与编号清单.md`：架构与模块规划；
- [`架构参考/`](架构参考/)：可复用的项目对照与架构决策资料；
- `ChatHub协议字段与状态流向总图.md`：协议字段与状态的唯一流向图；
- `交接文档-*.md`：阶段交接与当前工作上下文；
- `项目规划/`、`学习笔记/`：个人学习路线、求职计划、能力证据和复盘笔记，仅在本地保留，不属于项目交付物，也不提交 Git。

## 使用顺序

1. 先读最新交接文档、当前需求与协议流向图；
2. 个人学习进度与复盘按本地学习资料维护，不作为项目依赖；
3. 行为与协作流程仍以 [`../../工程协作章程/`](../../工程协作章程/README.md) 为准。
