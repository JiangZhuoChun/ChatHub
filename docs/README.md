# ChatHub 文档总览

> ChatHub 是当前主项目。与项目直接相关的需求、规划、学习笔记、协议和交接均从此目录读取和维护。

## 文档分类

- `W8-*.md`、`W9*.md`：已确认的需求与验收边界；
- `架构规划.md`、`代码架构重规划与编号清单.md`：架构与模块规划；
- `ChatHub协议字段与状态流向总图.md`：协议字段与状态的唯一流向图；
- `交接文档-*.md`：阶段交接与当前工作上下文；
- [`项目规划/`](项目规划/)：主线学习路线、技能清单、求职执行计划和 llfcchat 对照规则；
- [`学习笔记/`](学习笔记/)：W5–W9 的项目学习与复盘笔记。

## 使用顺序

1. 先读最新交接文档、当前需求与协议流向图；
2. 需要确认学习进度时读 `项目规划/`；
3. 需要回顾实现原理、踩坑与迁移经验时读 `学习笔记/`；
4. 行为与协作流程仍以 [`../../工程协作章程/`](../../工程协作章程/README.md) 为准。
